# Organization

Is the folder structure right? Folders to split/merge/rename/archive, misfiled docs, deprecated/duplicate content. Prefer minimal moves - relocating docs breaks links for cosmetic gain, so recommend a move only when it clearly pays for itself.

**Distinguish prescriptive from background.** Keep "how it actually works, verifiable against source" docs separate from "background investigation / research" material. Don't let exploration accumulate in the prescriptive tree.

## Severity

**Minor** - a stylistic inconsistency.

## Fix

Consolidate deprecated/duplicate docs per an explicit policy.
